How it works

  1. Connect your wallet — use the injected wallet in your browser (for example the wallet extension). There is no QR login, no server account, and never enter a seed phrase or private key anywhere on this page.
  2. Hold an Agent ID — only addresses that hold an Agent ID can check in. The app checks this on-chain, in your browser.
  3. Check in once a day — one check-in per UTC day. Come back tomorrow to keep your streak alive. Miss a day and your current streak resets.
  4. Climb the leaderboard — every check-in is an on-chain event, so streaks and rankings are public and verifiable.

Please note

  • Checking in is free — there is no fee charged by Agent Streak itself. You only pay the network gas for the transaction.
  • No return or income is promised. A streak is a record of participation, not an investment.
  • The smart contract is open-source. Verify it on the block explorer before interacting with it.
  • This page collects no sensitive data: no seed phrases, private keys, passwords, or personal information. Your wallet address is only used to read your on-chain streak.
