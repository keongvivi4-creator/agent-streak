# Promotion plan — Agent Streak: reach 30+ Agent ID holders

## Goal

- **Minimum (Innovation Award eligibility):** ≥30 distinct Agent ID holder
  addresses interact with the AgentStreak contract during the submission
  period (18 Nov – 9 Dec 2026).
- **Stretch (Growth Award ranking):** as many interacting Agent ID addresses
  and check-in transactions as possible; ranking uses interacting addresses +
  tx count/volume. Top 10 share 29,000 USDC.
- **Side quest (Community Promotion Award):** 20 X-post winners share
  2,000 USDC — posting about the project with `#BinanceWalletHackathon` +
  `#AgenticWallet` qualifies.

## Why holders will come (the honest pitch)

- It's free: a check-in costs ~0.0000025 BNB at current gas (a fraction of a
  cent) and there is no fee.
- It takes 10 seconds: connect wallet → one click → done.
- Streaks are public, persistent reputation: the leaderboard shows who shows
  up every day. Competitive holders will return daily to protect their streak.
- No new account, no token to buy, no risk: the contract cannot touch funds.

## Rules (do not break these)

- **Only real Agent ID holders, only voluntary check-ins.** No fake volume,
  no mass fake accounts, no bots farming interactions — the announcement
  explicitly disqualifies abnormal behavior / market manipulation.
- The agent never posts on X (no login). **Ayah posts from @trumpchains.**
  The agent only drafts copy.
- Never promise rewards, returns, or "passive income" in any copy.
- Never ask anyone for a seed phrase, private key, or pairing code.

## Channels

1. **X (@trumpchains)** — main channel. Post the launch, then a short
   reminder every 2–3 days + a weekly leaderboard screenshot. Always include
   `#BinanceWalletHackathon` and `#AgenticWallet` (also enters the Community
   Promotion Award). Tag @BinanceWallet / @BNBCHAIN sparingly (launch + one
   milestone).
2. **Binance Square** — repost the launch text as a Square post (same
   hashtags), if Ayah uses Square.
3. **Telegram communities** — share in groups Ayah already belongs to where
   self-promo is welcome (Agent ID / Binance Wallet / BNB Chain communities).
   Do NOT spam the airdrop channels the mint monitor watches.
4. **Direct outreach** — Ayah's contacts who hold an Agent ID (friends in
   the Agentic Wallet community). A personal message converts better than a
   broadcast: "coba check-in, gratis, streak lo masuk leaderboard".
5. **The product itself** — the leaderboard page is the retention loop:
   daily streaks + a visible "days until you lose your streak" nudge bring
   people back without new posts.

## Timeline

- **Day 0 (deploy + submit day):** launch post on X (EN + ID versions below),
  Square repost, first Telegram shares. Pin the X post.

- **Day 10 (28 Nov):** mid-campaign post — how many holders, top streaks.

## What to measure (weekly)

- Distinct interacting Agent ID addresses (read `CheckedIn` events).
- Total check-in transactions.
- Longest current streaks (for shout-outs).
- X engagement on the launch post (reposts, likes, clicks if visible).

## If growth stalls (<15 holders by day 7)

- Ask 2–3 holder friends directly for a check-in + repost.
- Post the leaderboard screenshot — social proof converts better than a
  feature list.
- Do NOT buy engagement, fake accounts, or pay for check-ins.
